# 工单与故障处理知识

工单 INC-1001 表示账单接口超时。推荐处理方式是先启用指数退避重试，再查看上游支付服务的 P95 延迟和错误率。如果连续三次重试失败，需要降级到异步补偿队列。

工单 INC-2002 表示向量库慢查询。常见原因包括 top_k 设置过大、metadata filter 缺少索引、热门 query 没有缓存、reranker 串行执行。可以先打开热门 query 缓存，再把 reranker 改成批处理。

对于高峰期请求，API 层不应该直接压到模型服务。推荐用队列削峰，把模型推理、检索、工具执行拆成独立 worker，并用 Redis 保存任务状态和取消标记。
